# Alchemy

![header](images/header.png)

Alchemy is a library that adds a rich set of editor extensions for Unity. It provides Inspector attributes, Hierarchy extensions, editor-window extensions, source-generated serialization extensions, and more.

https://github.com/annulusgames/Alchemy
